# Qanvas Hacker 增长方案

> 版本 1.0 · 2026-09-24 · 运营负责人视角
> 核心约束：**完全离线的 App 没有账号体系、没有后端** —— 增长引擎必须内建在产品里，一切以「生成物自传播」为杠杆。

## 0. 增长模型总览

```
AARRR 冷启动版（无后端）:
 Acquisition  ← 生成物水印 + 主题挑战 + 渠道内容
 Activation   ← 「下载模型前先看效果」Gallery 种子集 + 5 分钟首图
 Retention    ← 每日灵感 + 链式创作（生成→编辑→再编辑）
 Revenue      ← (开源免费，无营收 KPI；可承接赞助/Pro 高级功能)
 Referral     ← 参数卡片分享 = 复活种子（扫码即复现同图）
```

## 1. Acquisition（获客）

| 手段 | 设计 | 成本 |
|---|---|---|
| **生成物自传播** | 分享图右下角低饱和水印 "made with Qanvas · on-device 7B"，点进 README/GitHub | 0 |
| **参数复活卡** | 分享 PNG 的 metadata 写入 prompt+seed+size（PNG tEXt chunk），Qanvas 打开即"一键复现" | 0 |
| **主题挑战** | App 内置「本周挑战」提示词（运营侧每版更新 JSON，随版本发布），引导用户产同题作品 | 0 |
| **渠道矩阵** | 小红书（贴纸/手账向）、酷安（端侧 AI 向）、X/Reddit r/StableDiffusion（极客向）三套话术 | 内容制作 |
| **数据钩子** | 每版 Release Notes 附官方速度表 + 新机实测征集 | 0 |

**渠道话术要点**（诚实营销，不吹云级速度）：
- 卖点顺序：隐私（照片不出手机）> 离线无限量 > 7B 质量 > 透明贴纸独家
- 必须前置沟通「10GB 模型 + 旗舰机 20 分钟一张」的预期，转化低但留存高、差评少

## 2. Activation（激活）— 最陡漏斗的工程化破解

漏斗：安装 → 下载 10.3GB → 首图 ≈ 最难一步。

| 设计 | 目的 |
|---|---|
| 首页即「样图 Gallery」（APK 内置 8-12 张官方样图） | 先看到效果再决定下载，预期管理 |
| 下载器支持断点续传 + 校验 + 前台服务 | 弱网/中途退出可恢复，官方 downloader 已具备 |
| Wi-Fi 门禁 + 剩余流量提示 | 避免"偷流量"差评 |
| 下载完成后**默认 Tiny tier + 12 步**首图预设 | 首图 ~2 分钟出结果，跑通 aha-moment |
| RAM 门禁卡片（<12GB 给 Tier 建议） | 预期管理，防 OOM 差评 |

**北极星激活指标**：首次生成成功用时（目标 <10 分钟 from install，Tiny tier ~217s）

## 3. Retention（留存）

1. **链式创作**：画廊任意作品 → 「重生成」（换 seed）或「送去编辑」（图生图）→ 无限玩法循环。
2. **灵感库每日刷新**：内置 40+ 模板按四能力分类；「今日灵感」标题栏轮播。
3. **挑战模式**：同 prompt + 固定 seed，比谁的手机构图更稳（社区晒图素材）。
4. **里程碑系统**：累计 1/10/50 张解锁成就文案（纯本地，轻量）。

## 4. Referral（自传播飞轮）

**核心机制：参数卡片 = 复活种子**
- 分享的 PNG 内嵌完整参数 → 接收者用 Qanvas 打开 → 提示「检测到 Qanvas 参数卡，一键复现」→ 新用户由此进入下载转化页。
- 分享面板文案模板化：`我用手机本地跑 Qwen-Image-2.1 画了这个贴纸，0 上传 0 审查。参数已嵌图里，装 Qanvas 即可复现 📲`

**K 因子估算**：每张分享图触达 2-3 人，安装转化 5-10% → K ≈ 0.1-0.3（工具类健康区间）。

## 5. 运营节奏（发布日历）

| 时点 | 动作 |
|---|---|
| v1.0 发布周 | 酷安首发 + 小红书 3 篇贴纸教程 + X 发布帖（附速度表） |
| 每版本 | 更新「本周挑战」JSON + Release Notes 数据钩子 |
| 每月 | 征集用户作品 → 精选进 App 内置 Gallery（下版本收录，署名） |
| 长期 | 盯 libQwenImage21 上游：速度优化/多图编辑/新 tier → 跟版发「速度提升 X%」内容 |

## 6. 风险与合规

- **模型许可**：Qwen Research License = 研究/非商业。App 代码 Apache-2.0，模型页明示许可，不商业化模型输出。（若未来商用需换许可模型或谈授权）
- **性能预期**：所有渠道物料必须带真实耗时数据（官方 SD8Gen2 基准），不做云级速度暗示。
- **存储门槛**：11GB 是硬门槛，应用商店描述 + 门禁卡片双重告知。
