# Qanvas PRD — 端侧 Qwen-Image-2.1 创作工坊

> 版本 1.0 · 2026-09-24 · 产品负责人视角

## 1. 一句话定位

**Qanvas**（Qwen + Canvas）：把 7B 的 Qwen-Image-2.1 塞进你的口袋——完全离线的文生图、AI 改图、透明贴纸工坊。隐私 100%（零上传），创作 100%（端侧 7B 模型）。

## 2. 目标用户与场景

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 隐私敏感创作者 | 人物照片编辑（换装/换背景） | "我的照片不出手机" |
| 手账/贴纸爱好者 | 透明 PNG 贴纸 | 原生 RGBA 直出 |
| AI 玩家/极客 | 折腾端侧模型 | 透明性能数据、种子控制 |
| 弱网/无网环境 | 通勤、飞行、海外流量贵 | 完全离线可用 |

## 3. 功能矩阵（围绕模型四大能力 + 端侧约束设计）

### P0 — 首版必交付
1. **模型管家**：10.3GB 断点续传下载（官方 ModelDownloader）+ SHA 校验 + Wi-Fi 门禁 + 进度通知。
2. **文生图 Studio**：7 比例 × 3 档（Standard/Fast/Tiny）+ 步数/种子 + 实时进度（阶段感知：文本编码→DiT 步数→VAE）。
3. **AI 改图**：选图→描述改动→Fast 默认（保脸）+「为何 Fast 更保脸」上下文提示。
4. **透明贴纸工坊**：官方推荐 RGBA prompt 模板 + 棋盘格预览 + 一键导出 PNG。
5. **画廊**：输出文件管理、重生成（同 prompt 异 seed）、重编辑（图生图链式创作）。
6. **前台服务**：7.5 分钟任务不掉线，通知栏进度条+阶段文本。
7. **RAM 门禁**：启动时 MemAvailable 检查 + Tier 建议 + OOM 重试体验。

### P1 — 增长钩子（v1.x）
- Prompt 灵感库（分类模板：贴纸/海报/换装/换背景）
- 生成参数卡片（分享图带参数水印，可扫种子复活）
- 本地画廊导出/分享

### P2 — 未来
- 多参考图（等 runtime 支持多图编辑）
- Prompt 智能补全（本地小 LM）
- 平板双栏布局

## 4. 关键产品决策（PM 决策留档）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 打包官方 AAR v0.2.2，不自己编 libMNN | 2026-09-23 模型重导出后 runtime 版本强耦合，官方 AAR 已含 prebuilt .so |
| D2 | 编辑模式默认 Fast tier | 官方 README 实测：Fast 比 Standard 更保人脸，且省时 40% |
| D3 | 首启即显示「RAM/存储门禁」卡片而非埋在设置里 | 12GB+ RAM 推荐 → 提前管理预期，降低一星差评 |
| D4 | 长任务必用前台服务 | 7.5 分钟任务后台必被杀；前台服务+通知进度是唯一可行解 |
| D5 | 透明贴纸独立一级 Tab + 棋盘格预览 | 原生 RGBA 是本模型独家卖点，值得一级入口 |
| D6 | 版本策略 patch 递增（1.0.0 → 1.0.1） | 用户既有习惯（BiTrans 规范） |
| D7 | 灵感库用「效果第一」卡片流而非纯文本列表 | 付费流量下转化最高的展示形式 |
| D8 | 主打"隐私"叙事而非"免费" | "免费"拉来的用户对 10GB 下载容忍度低；"隐私"用户价值排序更高 |
| D9 | 三档渲染档位保留英文 Standard/Fast/Tiny | 与官方文档/社区语言一致，极客用户零学习成本 |

## 5. 成功指标

- 激活漏斗：安装 → 完成模型下载 → 首次生成成功 ≥ 60%
- 核心使用：周人均生成 ≥ 3 张
- 留存：D7 ≥ 15%（端侧 AI 工具类基准）
- 增长：分享率（生成→分享）≥ 25%

## 6. 竞品与差异化

- vs 云端 AI 绘画 App：零 token 费用、零审查、零上传（隐私）。
- vs 端侧 SD（SDroid/局部 diffusion）：7B 单流 DiT 对 1B UNet 的质量优势 + **原生透明贴纸 + 强编辑**（竞品无）。
- vs 官方 demo app：官方 demo = 工程验证 UI；Qanvas = 产品化（画廊、灵感库、前台服务、门禁、增长钩子）。
