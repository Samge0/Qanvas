Background Generation

7.5 分钟生成，息屏照跑

前台服务 + 对激进 ROM（MIUI/HyperOS、ColorOS、One UI…）的全套防御。

01 · WAKE LOCK

Partial wake lock 全程持有

整个任务期间 CPU 不休眠，息屏继续推理。

02 · SILENT AUDIO

静音音频保活

无声循环播放把进程归入「正在播放媒体」——没有任何 OEM 冻结器会挂起这个类别。

03 · FLOATING PILL

悬浮进度胶囊

「Qanvas · 37%」小窗常驻，GPU 调度永不饿死 OpenCL 命令流；任意 App 上方看进度。

04 · EXEMPTION

电池优化豁免

电池豁免 + 悬浮窗权限，都在「设置 → 后台运行」一键开启。

ROM 仍然卡住？终极保证：免费窗/小窗模式启动 Qanvas——应用可见即全速生成零冻结（多数 MIUI/HyperOS、ColorOS、鸿蒙都支持：最近任务 → 卡片下拉 → 小窗）。锁通知栏进度如「Text encoder → Denoising 7/20 → VAE decode」。
